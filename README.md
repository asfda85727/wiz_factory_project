# wiz_factory_project

# 노무비 관리 시스템

건설 현장 노무비를 관리자가 입력하고, 세금·4대보험을 자동 계산해 원청(LH) 제출용 엑셀 양식을 생성하는 내부 관리 시스템입니다.

## 배경

현재는 다음과 같은 흐름으로 노무비를 처리하고 있습니다.

```
TBM 종이 서명 → 한글파일 수기 입력 → 관리자 전달
→ 엑셀 서식(명세서_철거 등)에 재입력해 노무비·세금·차감지급액 계산
→ 매월 원청(LH) 제출
```

같은 정보가 세 번 손을 거치며 반복 입력되다 보니, 월 10회 이상의 수정/재작업이 발생하고 있습니다. 이 시스템은 서명 이후의 **반복 수기 입력 단계**를 제거하는 것이 목표입니다. (TBM 종이 서명 자체는 현장 안전관리상 필수 절차로 유지합니다.)

## 목표 사용자

| 역할 | 권한 |
|---|---|
| 관리자 | 현장 관리, 출역 입력, 단가 입력, 양식 매핑, 노무비 확인, 제출용 서식 생성 |
| 근로자 | 본인 출역일수·노무비 조회만 (입력 권한 없음) |

## 핵심 기능 (MVP)

| # | 기능 | 우선순위 |
|---|---|---|
| 근로자 마스터 데이터 | 인적정보 + 근로자×현장(공정) 단위 단가 관리 | P0 |
| 일별 출역 입력 | 현장·공정별 그리드 입력 | P0 |
| 노무비/세금 자동 계산 | 국세청 표준 공식 기반 자체 계산 (아래 참고) | P0 |
| 양식 필드 매핑 | 원청 엑셀 양식의 셀을 지정해 매핑 (최초 1회) | P1 |
| 월별 제출용 엑셀 생성 | 계산 결과를 매핑된 셀에 값으로 채워 생성 | P0 |
| 관리자 대시보드 | 현장/공정별 출근 인원, 세전·세후 노무비 합계 | P1 |
| 근로자 셀프 조회 | 전화번호+주민번호 앞자리 로그인, 조회 전용 | P1 |

## 노무비 계산 방식

세금·4대보험은 원청 엑셀의 함수를 그대로 이용하지 않고, **국세청·4대보험공단이 공개한 표준 공식을 시스템이 직접 계산**합니다. 계산된 값은 원천 데이터와 함께 원청 제출 양식의 매핑된 셀에 값으로 채워 넣습니다.

| 항목 | 기준 | 비고 |
|---|---|---|
| 소득세(갑근세) | (일당 − 15만원) × 6% × 45% | 일 단위, 나이 무관 |
| 지방소득세(주민세) | 소득세 × 10% | 10원 단위 절사 |
| 고용보험 | 일당 × 0.9% | 만 65세 이후 신규 채용자는 미적용 |
| 국민연금 | 기준소득월액 × 4.75% | 만 18~60세, 월 8일 이상 근무 시 가입 대상 |
| 건강보험 | 보수월액 × 3.595% | 나이 무관, 월 8일 이상 근무 시 가입 대상 |
| 장기요양보험 | 건강보험료 × 13.14% | 건강보험 가입자에 연동 |

> 요율은 매년 바뀌므로 코드에 하드코딩하지 않고 `insurance_rates` 테이블에서 연도별로 관리합니다. 실제 신고·납부 전에는 세무/노무 전문가 검토를 권장합니다.

## 기술 스택

| 영역 | 선택 |
|---|---|
| 백엔드 | Python (FastAPI) |
| 프론트엔드 | React (Next.js) |
| DB | PostgreSQL |
| 파일 저장 | S3 호환 오브젝트 스토리지 (AWS S3 / MinIO) |
| 배포 | Docker Compose |

민감정보(주민등록번호, 계좌번호)는 DB 암호화와 별개로 애플리케이션 레벨에서 AES-256-GCM으로 암호화 후 저장합니다.

## 데이터 모델 개요

```
users               관리자 계정
sites               현장
workers             근로자 (생년월일, 암호화된 주민번호/계좌번호 등)
worker_site_rates   근로자 × 현장(공정) 단가, 변경 이력 관리
attendance_records  출역 기록 (일 단위)
attendance_audit_log  출역 수정 이력
insurance_rates     연도별 세금/4대보험 요율
payroll_results     월별 계산 결과 (세목별 상세 포함)
form_templates      원청 제출용 엑셀 양식
field_mappings      양식 필드-셀 매핑
monthly_submissions 월별 제출 이력
```

## API 개요

| 영역 | 예시 |
|---|---|
| 인증 | `POST /api/admin/login`, `POST /api/worker/login` |
| 근로자 | `GET/POST /api/workers`, `POST /api/workers/{id}/files` |
| 현장/단가 | `GET/POST /api/sites`, `POST /api/sites/{site_id}/workers/{worker_id}/rates` |
| 출역 입력 | `GET/POST /api/sites/{site_id}/attendance` |
| 양식 매핑 | `POST /api/sites/{site_id}/templates`, `POST .../mappings` |
| 계산/제출 | `POST /api/sites/{site_id}/submissions/generate?month=` |
| 대시보드 | `GET /api/dashboard/summary`, `GET /api/dashboard/trends` |
| 근로자 조회 | `GET /api/me/attendance`, `GET /api/me/pay` |

## 시작하기

```bash
git clone <repo-url>
cd <repo-폴더>

# 환경변수 설정
cp .env.example .env

# 전체 스택 실행
docker compose up -d
```

> 개발 환경 상세 설정은 추후 업데이트 예정입니다.

## 명시적으로 하지 않는 것

- 실시간 GPS 기반 자동 출퇴근
- 지각/조퇴/결근 자동 판정
- 전자카드제·건설안전패스 연동
- 전자 근로계약서
- 인력 매칭/구인구직 기능
- TBM 종이 서명 절차의 대체 (현장 안전관리상 필수, 유지)
