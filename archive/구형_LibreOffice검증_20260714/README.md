# 보관 사유

2026-07-14 세션에서 "LibreOffice headless 재계산" 방식(원본 엑셀 수식을 그대로
재계산해 세금을 뽑아내는 접근)을 검증하던 스크립트들이다. Y6/Y7 세금 공식
해석이 사용자 지적값과 불일치해 막혀 있었다.

2026-07-16 기획서 갱신으로 이 접근 자체가 폐기되었다:
- 웹 명세서/셀프조회/대시보드 → **시스템이 직접 계산** (기획서 6.2의 명시적 공식)
- 제출용 엑셀 → **값만 채워 넣고 엑셀 자체 내장 수식이 파일 열 때 계산**
  (LibreOffice 재계산 불필요, openpyxl 값 채움만으로 충분)

즉 이 폴더의 스크립트들이 검증하려던 문제 자체가 더 이상 개발 경로에 없다.
삭제하지 않고 보관만 해둔다 — 세금 공식(6.2)을 실제 샘플과 대조 검증할 때
Y6/Y7 원본 수식 해석 시도가 참고가 될 수 있다.
